# UltiCa for Bright Nights

This fork aims to add more graphics dedicated to [Cataclysm: Bright Nights](https://github.com/cataclysmbn/Cataclysm-BN).

## Downloads and building

Get the packs from [this fork's releases](https://github.com/midgardormr/UltiCa-BN/releases). Build instructions are in [doc/ultica-bn.md](doc/ultica-bn.md).
